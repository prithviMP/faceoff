# Example datasets

Examples are bundled in `src/faceoff_lab/examples/` and included in the installed package. Work on a copy so your experiments do not modify the distributed data:

```sh
faceoff example policies workspace/policies
faceoff example support workspace/support
faceoff example refunds workspace/refunds
faceoff example iris workspace/iris
```

Each includes source data, project configuration and questions. The Iris example includes third-party attribution and license. The other three use clearly labelled synthetic data. See the main README and workshop for experiments and extensions.
